# Напоминалка — Telegram-бот для мастеров

Telegram-бот для управления записями клиентов, напоминаний, услуг, клиентов, отзывов и подписок.

## Состав проекта

- `bot.py` — основная логика бота.
- `support.py` — обработчик кнопки и команды поддержки.
- `admin_console.py` — дополнительная админ-консоль (включается через `ADMIN_CODE`).

## Требования

- Python 3.10 или новее.
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).

## Установка

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и задайте переменные окружения в панели хостинга или в локальной среде. Сам бот автоматически не загружает `.env`, поэтому при локальном запуске переменные нужно экспортировать отдельно либо использовать менеджер переменных окружения.

Обязательная переменная:

- `BOT_TOKEN` — токен Telegram-бота.

Полезные переменные:

- `ADMIN_ID` — числовой Telegram ID владельца.
- `TZ_NAME` — часовой пояс, по умолчанию `Europe/Moscow`.
- `DB_PATH` — путь к SQLite-базе, по умолчанию `bot.db`. На хостинге укажите путь к постоянному хранилищу, если оно предоставляется.
- `ADMIN_CODE` — секретный код админ-консоли. Любой, кто знает код, может получить права администратора, поэтому не публикуйте его и задайте длинное случайное значение.
- `SUPPORT_URL` — реальная ссылка поддержки. Не оставляйте значение-заглушку.
- `PAY_INFO`, `PAY_URL` — параметры оплаты, если используются.
- `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` — необязательные параметры AI-функций.
- `BACKUP_HOUR` — час ежедневной отправки резервной копии.

## Запуск

```bash
python bot.py
```

## Безопасность

Не добавляйте в репозиторий токены, пароли, `.env`, файлы SQLite (`*.db`, `*.sqlite*`), резервные копии или логи. `.gitignore` исключает типичные локальные секреты и данные. Если секрет случайно попал в публичный репозиторий, удалите его из истории и немедленно замените/отзовите секрет у соответствующего сервиса.

Перед развёртыванием проверьте настройки переменных окружения и постоянного хранилища на выбранном хостинге.
